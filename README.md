# robosys2026
## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境
- Ubuntu 24.04 LTS

## 使い方
リポジトリをダウンロードします。

git clone https://github.com/undake-man/robosys2026.git

ディレクトリに移動します。

cd robosys2026

プログラムを実行します。

python3 kadai1

表示された入力欄に、読み込みたい文章ファイルの名前を入力してください。

読み込むファイル名を入力してください：test.txt

ファイルが正常に読み込まれると、次の項目が表示されます。

空白を除いた文字数

行数

段落数

文数

## 課題の説明
- レポートの文章を読み込み、文字数（空白を除く）、行数、段落数、文数を数え、値を表示させる。
- 文章のファイルを読み込んだ時に起こるエラーの確認もできるようにした。
